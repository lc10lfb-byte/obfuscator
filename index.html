Sobre o projeto

O LC10 • OFUSCADOR foi criado com o objetivo de proteger scripts Lua/Luau para Roblox de forma simples, rápida e acessível.

Tudo roda direto no navegador — sem servidor, sem cadastro, sem enrolação.

Como funciona

O ofuscador combina várias técnicas:

Minificação → remove espaços e comentários inúteis

Renomeação → troca nomes de variáveis locais

Criptografia XOR → ofusca todas as strings do script

Loader protegido → envelopa o script num wrapper criptografado

Versão

Versão atual: v1.0

Suporte: Lua 5.1, Luau (Roblox)

Plataforma: navegador (mobile e desktop)
