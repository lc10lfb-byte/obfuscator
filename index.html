Sobre o projeto

O LC10 • OFUSCADOR usa uma VM própria com bytecode customizado — mesmo princípio de obfuscadores comerciais.

Tudo roda no navegador, sem servidor, sem cadastro.

Como funciona

Parse → Lua vira AST

Compile → AST vira bytecode custom

Pack → strings Base85 embaralhadas

Embed → VM interpretadora em Lua

Run → VM executa o bytecode

Versão

Motor: LC10 VM v4.0

Suporte: Lua 5.1, Luau (Roblox)

Plataforma: navegador (mobile e desktop)
